# Organigramme de GDS GED Services

Cette note décrit la structure hiérarchique de GDS, en explicitant clairement les
liens de rattachement entre chaque poste (voir aussi le schéma officiel de
l'organigramme).

## Direction générale

Le **PDG (Président Directeur Général)** est le responsable suprême de
l'entreprise, au sommet de la hiérarchie.

Le PDG a sous sa responsabilité directe le **Sénior Manager**.

## Rattachements directs du Sénior Manager

Le Sénior Manager encadre directement les postes suivants :

- Le **Responsable RH** (ressources humaines).
- Le **Responsable Technique Logistique**, en charge de l'archivage physique. Le
  **Matériel Roulant et transport** (pour l'archivage physique) est rattaché à ce
  Responsable Technique Logistique.
- Le **Responsable Production / Contrôle et qualité (RMA/BOA)**, qui supervise à
  son tour quatre superviseurs : le **Superviseur Réception**, le **Superviseur
  Préparation**, le **Superviseur Numérisation** et le **Superviseur Archivage**.
- Le **Responsable d'Atelier** du Centre d'indexation RMA.
- Le **Responsable projets CMIM, RMA ASSISTANCE** et autres projets similaires.
  Ce responsable encadre les **Chefs d'atelier**, qui encadrent eux-mêmes les
  **Superviseurs d'atelier**.
- Le **Responsable Administratif et financier**.

## Résumé des niveaux hiérarchiques

1. PDG
2. Sénior Manager
3. Responsables (RH, Technique Logistique, Production/Contrôle qualité RMA-BOA,
   Atelier, Projets CMIM/RMA ASSISTANCE, Administratif et financier)
4. Superviseurs (Réception, Préparation, Numérisation, Archivage, Chefs d'atelier)
5. Superviseurs d'atelier (sous les Chefs d'atelier)
